# valmir.dev — Personal Portfolio

My personal portfolio website, designed and built from scratch.

**Live site →** https://valmirmustafi1995-stack.github.io/Portfolio

## About

Single-file portfolio built with pure HTML, CSS and JavaScript — no frameworks, no dependencies. Deployed via GitHub Pages.

## Stack

- HTML5
- CSS3 (custom properties, animations, grid)
- Vanilla JavaScript (IntersectionObserver for scroll reveal)

## Features

- Fully responsive
- Scroll reveal animations
- Dark theme with custom design system
- Sections: Hero, About, Projects, Community, Contact
